# Remaining progression reward mechanics

These extend the implemented catalogue, cash, capacity, service and conversion rewards.
They are agreed design directions, not functional unlocks or claimed implementation.

| Mechanic | Providers | Required behaviour |
| --- | --- | --- |
| Map transition unlocks | Atlas, Ballast, Ledger, Boss | Overland, water, freight and operational passages; personal authoritative permissions; include shortcuts, keep optional contacts optional. |
| Suit skin application | Suture, Arena Master, Boss, scientists | Cosmetic-only unlocks; retain gameplay suit variant differences and base progression. |
| Storage expansion rewards | Cleaner | Bounded stored inventory expansions separate from carried rows; preserve contents and existing purchased storage. |
| Barter offers | Haggler, Latch, The Original, Egghead, Suture | Multiple specified input items for one output item; permanent offer unlock, inputs consumed on every exchange. |
| Supply exchanges | Gasket, Brass, Spicy Lemon, Jitters, Wake, Ledger, Intern | One specified input item for a defined bundle; validate output space, preserve recoverable pending delivery, audit resale loops. |
| Persistent useful information | Old Timer, The Original, Atlas, Mute, Smartass, Spoor, Wake, Vesper, Egghead, Intern, Spool, Carbon | Saved fieldcraft, maps, records, reports and communications functions with actionable authored content. |
| Cooking recipes | Spicy Lemon | Recipe permission and actual cooking consumer; no passive free food. |

Specific milestone allocations and proposed terms now live in each contact's `plannedUnlocks`, with an
adjacent `-- TODO:` on every entry. The [generated ledger](unlock-ledger.md#unimplemented-unlock-terms)
lists them all. They count toward planned coverage only and are absent from runtime entitlements and menus.
Validate and balance the proposed terms, author the full content and verify destinations when implementing
each consumer. Do not convert metadata into rewards merely by listing it in a task description.
Do not count an unimplemented entry as the reward for a completed objective. Existing network,
broadcast and emission-warning services remain under their current milestone checks.

TODO plans remain authoring metadata. All 624 active steps now have implemented unlocks or meaningful
stock improvements after the personality-based redistribution. Temporary provision gifts were removed;
original gifts and cash remain. Arena Master's old progression and eight TODO plans are retained only
as inactive reference data. Existing objective and equipment prerequisites still apply.
